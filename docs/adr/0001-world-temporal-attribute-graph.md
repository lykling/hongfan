# ADR-0001：世界状态 = 时态属性图

- **状态**：已接受
- **日期**：2026-09-08
- **决策者**：Pride Leong
- **关联**：[00-design.md](../00-design.md) §3.2、D1

## 背景

洪范的核心承诺是"引擎与万物皆有联系"：实体间关系（人与床、村庄与隔壁村庄）和引擎与世界的关系都必须是一等公民。纯关系事实表（Datalog 风格）表达联系笨拙；而"某时刻世界什么样"的回溯查询（切面、还原、编年史的根基）要求状态天然带时间。

## 决策

世界状态建模为**带有效时间的属性图**：

- 节点 = 实体（可抽象"民心"可具体"铁锭 #42"），边 = 有类型联系（可带属性）
- 每项数据附带 `valid_from / valid_to`，状态历史 = 事实的有效期记录
- "某时刻的世界"是 as-of 查询而非独立存储
- M1 形态：实体槽位稳定（无删除）、`std::map` 有序容器保证迭代序与序列化规范序

## 后果

- 联系自然承载"世界之心"哲学：引擎对世界的观察/驱动/被扰动都建模为图上的操作
- 实现复杂度高于表结构；时态存储需要 GC/归档策略（开放问题，见 00-design §15）
- 有序容器（红黑树）是确定性契约（附录 A）的地基——禁止依赖无序哈希迭代
