# ADR-0002：YAML DSL + 受限表达式，禁宿主语言代码

- **状态**：已接受
- **日期**：2026-09-08
- **决策者**：Pride Leong
- **关联**：[00-design.md](../00-design.md) §5、D2；[01-implementation.md](../01-implementation.md) §5

## 背景

规则要支持三种能力：静态校验（类型/绑定封闭/守恒）、逆向还原（反向应用规则）、可复现（Run 四元组重放）。任意宿主语言代码一旦混入规则，三者全部失效——无法分析、无法反转、无法保证复现。

## 决策

- **宿主格式 YAML**：人类可读可写、利于 diff；JSON 为等价机器交换格式
- **自研受限表达式**：纯函数、无副作用、无循环、可静态分析；`rand_*` 仅允许出现在效果表达式（加载期静态拒绝其余位置）
- M1 实现偏差：ryml 分发资产不可得，自研受控 YAML 子集解析器（块映射/块序列/单行 flow map/引号标量/整行注释）

## 后果

- 表达力受限：复杂函数走外部函数注册表，显式标记 `reversible: false`（把不可逆性显式化）
- 受限表达式使守恒校验、因果序检查、rand 位置检查都在加载期一次完成
- 子集受控意味着解析器行为完全可预测（跨编译器可移植性已由 GCC+Clang 双门禁验证）
