# ADR-0003：确定性内核 + 外部注入种子化 RNG

- **状态**：已接受
- **日期**：2026-09-08
- **决策者**：Pride Leong
- **关联**：[00-design.md](../00-design.md) §6.5、D3；附录 A

## 背景

洪范的可复现承诺：**Run = (ruleset_hash, initial_state_hash, strategy_config, seed) → 唯一轨迹（含编年史字节序）**。没有这条，平行世界对比、黄金文件回归、正向重放验证（还原出的历史必须真能重走一遍）全部无从谈起。

## 决策

- 内核纯函数式：同样的输入必然产出同样的轨迹
- **一切随机性只来自注入的种子化 RNG**（SplitMix64，~20 行自实现，跨平台位一致）：规则的 `probability`、效果里的 `rand_int`、策略采样，全部走它
- RNG 消耗点全量枚举、顺序固定（附录 A.3）：门控按候选规范序逐候选消耗（p=1 不消耗）、策略 pick、效果 rand、全局采样
- 失败也确定：求值错误/不变量违反时消耗的 RNG 不回退（消耗序列连续性优先）

## 后果

- DSL 里写随机必须显式走 `rand_*`，纪律成本
- 同一 Run 四元组重放逐字节一致（e2e 用双跑 `cmp` 验证，黄金文件回归锁定）
- "失败不回退 RNG" 是反直觉但有意的选择——保证任何调度/重试下消耗序列不变
