# ADR-0005：分层世界结构由作用域树承载

- **状态**：已接受（v0.3 修订，原 v0.2 为 layer 纯元数据）
- **日期**：2026-09-11
- **决策者**：Pride Leong
- **关联**：[00-design.md](../00-design.md) §8、D5；[0011](0011-partitioned-determinism.md)、[0014](0014-attention-expand-condense.md)

## 背景

宏观/微观分层（文明层 vs 人物层、村庄 vs 房间）需要的不只是标签：层需要**实体边界**（房间里的人/桌/椅）、**局部时钟**（微观快宏观慢）、**信息边界**（作用域内只知本地事实+收到的消息）。纯 layer 元数据给不了这些，"不知道"本身无法被建模。

## 决策

- 作用域（Scope）= 世界状态的一级分区：实体/关系子集 + 规则视图（ScopeProfile）+ 局部时钟 + 消息收件箱
- 作用域构成树（房间 ⊂ 村庄 ⊂ 世界）或更一般的图；子作用域在父作用域中以摘要切面存在
- `complete(scope, B, P, bounds)` 带作用域参数；匹配空间被裁剪（性能与信息语义双重收益）
- layer 降为规则元数据，用于作用域内的规则过滤与多分辨率编年史

## 后果

- 作用域管理复杂度进入引擎（M6 落地）
- 跨层一致性从开放问题升格为硬需求（宏观锚点约束微观还原，见 [0014](0014-attention-expand-condense.md)）
- 无全局同时刻——查询语义变化，见 [0011](0011-partitioned-determinism.md)
