# ADR-0008：切面（Slice）为一等类型

- **状态**：已接受
- **日期**：2026-09-08
- **决策者**：Pride Leong
- **关联**：[00-design.md](../00-design.md) §3.2、D8；[0009](0009-three-state-solution-space.md)

## 背景

对世界的观测天然是**部分的**（"城市已成废墟"而非全量快照）且**可错的**（两份史料各执一词）。把输入限定为完整快照等于否认观测的本质。

## 决策

```
Slice = { at: 时刻, facts: 部分事实断言集, confidence: 可信度 0..1 }
```

- **部分性**：只断言"这些成立"，不断言其余；单事实 = 最小切面（`explain` 的输入）
- **可信度**：矛盾松弛（[0009](0009-three-state-solution-space.md)）的权重来源
- 完整快照 = confidence 1 的极大切面（特例而非基准）
- 作用域间的消息 = 跨边界投递的切面（v0.3）

## 后果

- 接口必须区分"断言成立"与"未断言"——三值语义侵入实现
- 矛盾输入从异常变为常态：真实世界的信息本就不一致，引擎负责给出"最接近的解释"而非报错
