# ADR-0009：解空间三态——唯一、多解、矛盾松弛

- **状态**：已接受
- **日期**：2026-09-08
- **决策者**：Pride Leong
- **关联**：[00-design.md](../00-design.md) §2.4、§7.7、D9；[0008](0008-slice-first-class-type.md)

## 背景

补全结果由规则完善程度与切面约束共同决定。若只考虑"有解/无解"，矛盾输入（两份编年史对同一场战役记载冲突）就只能报错——而"最接近的解释"本身有价值。

## 决策

| 性态 | 条件 | 行为 |
|---|---|---|
| 唯一解 | 规则完备确定 | 纯计算，策略不参与 |
| 多解 | 欠定（概率/冲突/自由度） | 策略选取 |
| 无解 | 过定或切面冲突 | **松弛**：argmin Σ 违背权重×(1−可信度) |

松弛结果按违背度升序输出 + 结构化违背报告（哪些断言被牺牲），标记 `degraded` 与严格解区分。

## 后果

- 松弛本身是加权优化问题，复杂度高——限界松弛（只松弛低可信度断言）、贪心近似作为对策
- v0.3 补充：注意力有损压缩让"欠定"成为常态，被压缩的细节以多解自由度回归（解释空间的来源）
