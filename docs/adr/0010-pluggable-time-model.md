# ADR-0010：时间模型接口化，因果序为声明式约束

- **状态**：已接受（v0.3 增补作用域化）
- **日期**：2026-09-08
- **决策者**：Pride Leong
- **关联**：[00-design.md](../00-design.md) §6.4、D10；[0005](0005-scope-tree-layering.md)、[0011](0011-partitioned-determinism.md)

## 背景

时间不是引擎的背景参数而是世界的组件：不同世界需要不同的时间流动方式（稀疏大世界适合事件驱动；分层世界需要多速率；叙事需要分支平行世界）。

## 决策

- TimeModel 为规则集声明的可替换组件：**linear-tick**（默认）/ event-driven / multi-rate / branching
- **因果序**：规则 `ordering.precedes` 声明构成事件偏序；离线补全时事件先后本身是待求解的自由度（搜索空间含顺序选择）
- v0.3 增补：时间模型作用域化——各作用域独立局部时钟、惰性跳步（无规则可火的作用域直接跳到下一事件时刻）；全局只剩因果对齐点

## 后果

- "顺序也是待补全的"让还原更强大也更昂贵（搜索空间多一个维度）
- 多速率/分支时间模型的存储与 as-of 查询复杂化——v1 只实现 linear-tick，其余先定接口语义
- 远期（不进 v1）：局部时间（区域时间停滞/加速）等时间玩法的规则化表达
