# ADR-0011：分区确定性——并行性与可复现性共存

- **状态**：已接受（v0.3）
- **日期**：2026-09-11
- **决策者**：Pride Leong
- **关联**：[00-design.md](../00-design.md) §8.3、D11；[0003](0003-deterministic-kernel-seeded-rng.md)、[0005](0005-scope-tree-layering.md)

## 背景

作用域是天然并行单元（M6），但确定性契约（[0003](0003-deterministic-kernel-seeded-rng.md)）若被线程调度序破坏，平行世界对比与重放验证全部失效。分布式系统的经典难题：无全局时钟下如何定义"发生顺序"。

## 决策

1. **区内**：串行规范序完全不变（附录 A 原样适用于每个作用域）
2. **跨区**：唯一交互通道 = **消息**（切面 + 发送方局部时刻）；定序 =（发送方局部刻， 发送方规范序）
3. **全局轨迹** = 各作用域轨迹按消息序显式编织的**因果偏序**——不是全局时间线

调度序（谁先跑）**不得**进入输出：任何并行调度下，消息定序相同则编织结果相同。可复现性从"重放一条线"升级为"重放一张因果网"。

## 后果

- **没有全局同时刻**：每个作用域有自己的"现在"，对齐只能沿消息因果序（相对论式世界模型）
- 跨作用域查询必须显式声明对齐策略；"世界快照"= 按消息序对齐的显式编织
- 消息定序进入确定性契约（附录 A.6）；M6 首个验收 = 并行重放一致性测试
