# ADR-0012：个体规则 = 数据（规则即数据）

- **状态**：已接受（v0.3）
- **日期**：2026-09-11
- **决策者**：Pride Leong
- **关联**：[00-design.md](../00-design.md) §9、D12；[0007](0007-single-rule-execution-mechanism.md)、[0016](0016-llm-boundary.md)

## 背景

"一切皆规则"若只停留在类级（Person 的行为规则人人相同），个体的个性（阿岩的坚毅、性惰者的偷懒）就只能退化成数值参数，无法参与推理与还原——还原历史需要"当时的性格"。

## 决策

- 规则分片（rule fragment）可附加于**个体**：类规则之外，阿岩携带"遇挫后练剑意志 +0.2"分片，可覆盖类规则的 guard/优先级
- 规则既是推衍的依据，**也是世界状态的一部分**（性格是被规则描述的事实）
- **生成**：元规则实例化（性格模板→参数化实例，受控随机可复现）或 LLM 接缝 S1（[0016](0016-llm-boundary.md)：生成过静态校验器裁决，拒收即拒收）；产物带 provenance
- **时态化**：分片带 valid_from/to，与[时态事实图](0001-world-temporal-attribute-graph.md)同构；性格变化本身可以是规则应用的结果（顿悟、变故）
- **寻址**：个体分片计入 ScopeProfile 哈希——个体差异被可复现性覆盖

## 后果

- 分片级索引与哈希成本；规则数量膨胀风险（分片按类型分桶索引缓解）
- "用规则生成规则"是元层的第一次登场，M1 刻意不展开（M7 原型）
