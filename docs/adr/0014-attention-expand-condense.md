# ADR-0014：注意力 = 展开/压缩对偶

- **状态**：已接受（v0.3）
- **日期**：2026-09-11
- **决策者**：Pride Leong
- **关联**：[00-design.md](../00-design.md) §10、D14；[0005](0005-scope-tree-layering.md)、[0008](0008-slice-first-class-type.md)、[0009](0009-three-state-solution-space.md)

## 背景

世界不必整体推衍：注意力所在之处应精细展开，其余粗粒度休眠。这需要一个统一的概念把"推演细节"与"降低分辨率"组织成同一机制，而非两个独立功能。

## 决策

| | 展开（注意力进入） | 压缩（注意力离开） |
|---|---|---|
| 操作 | forward 推演微观细节 | 投影成粗粒度摘要切面 |
| 信息 | 细节齐全（轨迹，可重放） | 有损——细节佚失，只留摘要 |
| 形态 | 确定的历史 | 切面 + 叠加（待还原的解集） |

- **压缩不是删除，是降分辨率**；损耗落在"佚失/不可逆"概念上——被压缩的细节在还原时以多解自由度回归
- **延迟还原 + 惰性坍缩**：对压缩切面跑稽疑得解集，可不立刻选取；新证据（新切面）到来收紧解集，直到有人"看"才坍缩
- **注意力是策略也是接口**：焦点分配（哪个作用域、什么粒度、什么频率）由上层（叙事导演、玩家视角）驱动——世界之心不观视，观视来自世界之外

## 后果

- 推衍 = 展开，还原 = 压缩之逆，`complete()` 原语两头通用（概念闭环）
- **跨层一致性升格为硬需求**：压缩有损后，微观还原可能违反宏观摘要——宏观锚点作还原约束，冲突走松弛
- 压缩态天然是存储节省（M7 验收："隔壁村庄之死"全场景走查，见 00-design §10.5）
