# ADR-0016：大模型的角色——创作与讲述，不裁决

- **状态**：已接受（原 [01-implementation.md](../01-implementation.md) §2 ADR-2，v0.3 起为此正式编号）
- **日期**：2026-09-11
- **决策者**：Pride Leong
- **关联**：[01-implementation.md](../01-implementation.md) §2；[0003](0003-deterministic-kernel-seeded-rng.md)、[0012](0012-instance-rules-as-data.md)

## 背景

洪范的核心承诺：Run 四元组可复现、轨迹可验证、不变量必守。大模型作为推衍核心三者全破坏（三杀）：**不可复现**（同输入 ≠ 同输出）、**不可验证**（输出无合规性保证，错误进事实图被无限放大）、**成本不规模**（推衍是 O(tick)×O(规则) 内循环，LLM 是 O(1) 外部服务，延迟把世界之心变成世界之邮局）。

## 决策

**原则：LLM 的输出永远是被校验的数据，或已定数据的投影，绝不充当合法性判据。**

六个接缝（S1–S6）：

| 接缝 | 输入→输出 | 谁裁决 |
|---|---|---|
| S1 规则创作 | 自然语言 → 规则草案 | 规则集加载校验器，拒收即拒收 |
| S2 切面提取 | 史书文本 → 切面断言+可信度 | 切面 schema + 表达式静态检查 |
| S3 叙事渲染 | Step 序列 → 风格化编年史 | 无需裁决（数据已定，渲染是投影，不参与轨迹 hash） |
| S4 偏好策略 | "还原战争史诗" → 打分/过滤 | 只能在已验证的合法解集内排序 |
| S5 搜索启发 | 目标+节点 → 优先尝试序 | 引擎逐个正向验证，启发错=慢不会=错 |
| S6 自由度填充 | 已定轨迹 + 空白细节 → 物化文本 | 显式分层，轨迹 hash 不含物化文本 |

**确定性保护条款**：经典内核的 Run 复现域内零 LLM 调用；LLM 产物入库一律走内容寻址工件 + provenance（模型/prompt/输出 hash）。

## 后果

- 引擎是天道，大模型是史官与文人：天道管合法，史官管好看
- 各接缝独立演进（S1/S3 是 M7 前后的原型验证目标），校验边界各自维护
