# ADR-0017：语言政策——文档与代码注释随项目之声（中文），提交信息英文

- **状态**：已接受
- **日期**：2026-09-11
- **决策者**：Pride Leong
- **关联**：[01-implementation.md](../01-implementation.md) §1.3

## 背景

洪范以《尚书·洪范》为名，模块借九畴命名，编年史输出中文叙事——项目具有鲜明的中国文化特征。注释与文档用什么语言、提交信息用什么语言，需要一次明确的裁决；两者诉求不同（项目之声 vs 工具生态兼容），不应捆绑决策。

## 决策

| 层 | 语言 |
|---|---|
| 文档（docs/） | 中文 |
| 代码注释 | 中文 |
| 字符串字面量（诊断+呈现） | 中文 |
| 提交信息 | 英文（Conventional Commits） |
| 标识符 | 英文 |

## 后果

- 项目之声贯穿文档、注释与运行时输出，与编年史的中文叙事一体
- 提交历史对约定式提交工具链与跨语言检索友好
- 强制由既有机制承担（提交钩子与 CI），本文只记录决策、不规定流程
- 若未来国际化需要英文注释，可按文件渐进引入，无需推翻本 ADR
