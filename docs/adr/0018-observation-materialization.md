# ADR-0018：观测即落盘（materialization）与世界线绑定

- **状态**：已接受
- **日期**：2026-09-11
- **决策者**：Pride Leong
- **关联**：[00-design.md](../00-design.md) §10.6、[0010](./0010-pluggable-time-model.md)、[0014](./0014-attention-expand-condense.md)

## 背景

v0.3 的延迟还原只回答了"何时坍缩"，未回答坍缩之后结果是否持久。若不落盘，同一区域反复观测将反复重推——每次稽疑可能采出不同的微观史，世界随观看而抖动，观测失去幂等性。

## 决策

- **观测即落盘**：第一次观测强制求值，展开产生的新事实写入**史册层**（provenance: `derived-on-observation`）；重观测读史册（as-of 查询），永不重推
- **两层记忆**：工作态（摘要切面）/ 史册层（既定事实全集）；压缩只作用于工作态，不焚毁史册
- **翻案**：新切面与既定事实矛盾 → 显式 reopen → 矛盾松弛按可信度裁决
- **世界线绑定**：`observe(scope, { worldline: bound | fork(k) })`——默认绑定当前线（重观测幂等）；fork(k) 一次分叉 k 条世界线（DiversityPolicy 最异解），各线独立落盘、可各自继续推衍

## 后果

- 观测幂等，世界稳定："被观测到的事实成为既定事实，重复观测不重推"
- 多元宇宙语义显式化：默认单线确定，多元是显式选择而非隐藏行为
- 史册层存储持续增长——与编年史同构，沿用归档策略；derived 事实带 provenance 可审计
